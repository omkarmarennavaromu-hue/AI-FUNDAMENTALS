# AI Fundamentals — AI Advent Calendar

A responsive, interactive recreation of the AI Advent Calendar lesson experience. It includes the nine field-note lessons, a lessons/windows home page, and an About Me page for Omkar R. Marennavar / Omvex Studio with Instagram and email links. Lesson pages include their plain-English definition, a small concept diagram, the three-step explanation, and previous/next lesson navigation. A creator signature watermark is included in the site footer.

## Run locally

```sh
node server.js
```

Then open `http://localhost:3000`. Deep links such as `/lesson/embeddings` are served directly by the app.

The original reference pages were used for the lesson copy and the page structure. Colors, typography, and visuals are a handcrafted reconstruction; the original site’s rendered styles were not exposed by the text-only page extraction.
