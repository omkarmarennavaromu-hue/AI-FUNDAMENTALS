## Installed skills

### Day Trader skill (11 trading skills)

Project-local install of [Jakeschincariol/day-trader-skill](https://github.com/Jakeschincariol/day-trader-skill)
v2.0.0 (MIT), in `.claude/skills/`. See `.claude/skills/INSTALL.md` for the
full notes, verification results and safety review.

Commands: `/trader-scanner`, `/trader-news`, `/trader-entry`, `/trader-exit`,
`/trader-timemachine`, `/trader-risk`, `/trader-budget`, `/trader-broker`,
`/trader-alerts`, `/trader-analyst`, `/trader-pelosi`.

Nothing to pip install (standard-library Python 3.8+). Runtime state and the
editable settings live in `trader/` (`trader/config.json`).

Not financial advice. Paper trading is the default; no order can be placed
without your explicit yes.
